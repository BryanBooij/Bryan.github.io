What did i do

  • Acted as the lead developer, managing and maintaining the project's GitHub repository and supporting version control and collaboration within the team.
  • Developed and implemented the core gameplay systems in Unity using C#, including the player, enemies, asteroids, bosses, spawners, and laser attacks.
  • Implemented the behaviour and functionality of gameplay objects through scripts, bringing the team's visual assets to life within Unity.
  • Developed the story mode with a planet map, where players unlock the next planet by completing level 5 of the previous planet.
  • Created a level selection screen featuring locked levels, star ratings, and high scores.
  • Implemented boss fight mechanics, including a health bar displayed at the bottom of the screen.

Results

The project resulted in a playable 2D space shooter with a story mode, multiple levels, enemy types, asteroid spawners, and boss fights. I implemented the main gameplay mechanics using C# scripts in Unity and helped keep development organised by managing the GitHub repository. The project brought together the work of the development, art and design team into a functional game. One of the main achievements was implementing the different gameplay systems and making them work together.

What I Learned

During this project, I improved my C# and Unity skills, especially in developing gameplay mechanics, managing game objects, and connecting different scripts and systems. As lead developer, I also learned more about maintaining a GitHub repository, handling merges, and collaborating with other team members. One of the biggest challenges was fixing merge conflicts andfixing bugs and making sure new features did not break existing functionality. In future projects, I would focus more on testing changes regularly, keeping the code organised, and communicating technical changes clearly to the rest of the team.
